# DDX AI — нативная версия (Expo)

Тот же чат, что на сайте: тот же воркер, тот же аккаунт, чаты и тариф синхронизируются.

## Запуск на айфоне с винды (бесплатно)
1. Поставь Node.js (LTS) и **Expo Go** из App Store.
2. В папке `ddx-expo`: `npm install`, затем `npx expo start`.
3. Отсканируй QR камерой айфона. Телефон и комп должны быть в одной wifi-сети (иначе `npx expo start --tunnel`).

## Что есть
чаты (список, поиск, закрепление, переименование, удаление), markdown и код с копированием, модели Liama / Mistral, поиск в интернете, источники, подсказки продолжения, память, настройки тона и стиля, вход в аккаунт и облачная синхронизация, тарифы и коды, лимит сообщений.

Пока нет: фото и файлы в сообщениях, голосовой ввод, проекты, уведомления.

## Настоящее приложение (.ipa)
`npx eas-cli login`, потом `npx eas-cli build -p ios --profile preview`. Нужен apple id; без платного аккаунта разработчика ($99/год) приложение живёт 7 дней.

Воркер получает запросы с заголовком `Origin: https://gdev49df.github.io` (см. `src/api.ts`), поэтому менять `ALLOWED_ORIGINS` не нужно.
